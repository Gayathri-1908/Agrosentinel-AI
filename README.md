# AgroSentinel AI 🌱

AgroSentinel AI is a two-tier satellite and leaf intelligence
system for early crop stress monitoring.

## Team

- P. Gayathri
- M. Mirudula
- E. Naga Srinuja

## Project Workflow

Farm Boundary
→ Sentinel-2 NDVI
→ Weather Fusion
→ Risk Zone Map
→ Field Inspection
→ Leaf Upload
→ Disease Prediction

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Leaflet

### Backend
- FastAPI
- Supabase / PostgreSQL

### Satellite & Weather
- Sentinel-2
- Sentinel Hub / Copernicus
- Open-Meteo

### AI
- MobileNetV3 / EfficientNet-B0
- Grad-CAM
